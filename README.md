# Spotify Web Player Clone 🎵

A responsive Spotify-inspired web player interface built using HTML and CSS. This project replicates the look and feel of Spotify's desktop web application, featuring a sidebar navigation menu, library section, playlist cards, trending music recommendations, and a sticky navigation bar.

## Features

🎧 Spotify-inspired user interface

🎵 Recently Played and Trending Music sections

📚 Interactive Library Panel

📱 Responsive Design

🖼️ Music Cards with Hover Effects

📌 Sticky Navigation Bar

🎨 Modern Dark Theme UI

⚡ Smooth CSS Transitions and Animations

## Technologies Used

* HTML5
* CSS3
* Font Awesome Icons
* Google Fonts (Montserrat)
